# 1장 요약직보자료 정확도 점검 (2026-09-16)

선생님이 알려 주신 네 가지(어휘 선정·동반의어, 어법 설명 오류, 밑줄 불일치, 해석 오류)를 정수학원 실제 지문
6개로 확인하고 고쳤다. 지문은 종류가 겹치지 않게 골랐다.

| 지문 | 문장 수 | 갈래 |
| --- | --- | --- |
| 친환경 제품 구매 후 도덕적 면죄부의 위험 (9af801ed) | 7 | 심리·논설 |
| 자본주의의 불평등과 위기 (932e8615) | 7 | 사회·추상 |
| 소행성이 지구에 미친 영향과 그 결과 (ca247025) | 8 | 과학·설명 |
| 스포츠에서의 규범적 속임수 사례 (5047b4e8) | 7 | 예시 나열 |
| 학생회장 후보로서의 불안과 고민 (0598c668) | 12 | 편지글 |
| 다양한 경험이 즐거움을 높이는 이유 (442a8cdd) | 15 | 조언·설명 |

채점은 내신 영어 교사 기준으로 항목마다 직접 했다.
어법은 "이 문장에서 맞는 형태가 하나뿐인가, 설명이 참인가", 동반의어는 "이 문맥의 이 뜻·이 품사에 맞는가",
밑줄은 "밑줄이 설명이 말하는 것을 그대로 덮는가", 해석은 "영어가 말한 것을 그대로 옮겼는가"를 본다.

## 고치기 전 (op-3)

**어법 포인트 28개**

| 문제 | 개수 |
| --- | --- |
| 두 형태가 다 맞아 답이 하나가 아님 | 3 |
| 설명이 틀리거나 한국어가 비문 | 5 |
| 출제할 수 없는 자리(조동사 뒤 동사원형, 주어 바로 앞 인칭 일치, 없는 오답 형태) | 10 |
| 적어도 하나에 걸린 것(합집합) | **17 / 28 (61%)** |
| 밑줄이 설명과 어긋남(근거가 밑줄 밖) | 6 / 28 |

보기:
- `to compensate / compensating` — "seek는 목적을 나타낼 때 to부정사를 취한다"는 없는 규칙이고, 분사로 읽으면 둘 다 된다.
- `would have caused / would caused`, `should I run / should I ran` — 조동사 뒤 동사원형(금지 항목).
- `they feel / feels`, `I am cut out / is cut out`, `Humans enjoy / enjoys` — 주어가 동사 바로 앞이라 시험이 되지 않는다.
- `to slow down / slow downing` — 영어에 없는 형태.
- 밑줄 `are still visible`인데 설명은 "outlines가 복수라서" — 근거가 밑줄 밖.

**어휘 53개**

| 문제 | 개수 |
| --- | --- |
| 동의어·반의어가 그 뜻·품사에 맞지 않음 | **25 / 53 (47%)** |
| 고를 낱말이 아님(중학 수준·고유명사·구·같은 어근 중복) | 18 / 53 (34%) |

보기: `diameter ↔ radius, circumference`(반대말이 아니다), `asteroid ↔ comet, planet`,
`wages ↔ unpaid labor, poverty`, `petition ≒ petitioning`(품사 불일치),
편지글 지문은 8개 중 6개가 구여서 "표현 바꿔 쓰기"와 그대로 겹쳤다.

**해석** 요약문 해석 6개 중 0개, 표현 뜻 25개 중 2개, 어법 설명 한국어 3개가 어색하거나 틀렸다
(예: "동사는 are가 맞아 한정적 단수 is는 틀리다", "주어 you에 맞춰 don't(복수형)").

## 고친 뒤 (op-4)

같은 지문 6개를 다시 만들어 같은 기준으로 채점했다.

| 항목 | 고치기 전 (op-3) | 고친 뒤 (op-4) |
| --- | --- | --- |
| 어법 포인트 수 | 28 (지문당 4~5) | 27 (지문당 4~6) |
| 두 형태가 다 맞음 | 3 | **0** |
| 설명이 틀림·한국어가 비문 | 5 | **1** |
| 출제할 수 없는 자리 | 10 | **1** |
| 어법 이름표가 실제와 다름 | (세지 않음) | 4 |
| 하나라도 걸린 것 | **17 / 28 (61%)** | **6 / 27 (22%)** |
| 그중 정답이 하나가 아니거나 설명이 틀린 것 | 13 / 28 (46%) | **2 / 27 (7%)** |
| 밑줄이 설명과 어긋남 | 6 / 28 | **0 / 27** |
| 어휘 수 | 53 | 48 |
| 동의어·반의어가 틀림 | **25 / 53 (47%)** | **4 / 48 (8%)** |
| 고를 낱말이 아님 | 18 / 53 (34%) | **2 / 48 (4%)** |
| 한국어 뜻이 엉성함 | 4 | 3 |
| 해석 오류(요약문·표현 뜻) | 2 | **0** |
| 지칭 정리 | 없음 | 14개(지문당 0~4), 가리키는 대상이 틀린 것 0개 |

고친 뒤 남은 6개는 이런 것이다.
- `should I run`의 run(조동사 뒤 동사원형) — 시험에 낼 수 없는 자리인데 한 번 통과했다.
- `lucky enough to win`의 win을 "if절이라 현재시제"라고 설명했다 — 답은 하나지만 이유가 틀렸다.
- `a huge cloud`의 huge를 "주격보어 형용사"라고 이름 붙였다 — 설명은 맞고 이름만 틀렸다(4건).

## 무엇을 바꿨나

1. `src/lib/lesson-materials/one-page-grammar-rules.ts`(새로 만듦) — 워크북 어법 선택 엔진의 교재 규칙
   (`grammar-choice-v2/textbook-rules`)·이름표(`grammar-ontology`)·출제 제외 목록(`generation-policy`)을 그대로
   써서 정리자료가 쓸 수 있는 어법 60가지를 만든다. 교재가 "둘 다 가능"이라고 적은 자리(동명사 주어,
   콤마 없는 관계절의 that/which, help 뒤 원형/to V, if/whether, 강조구문 that/who 등)는 `ONE_PAGE_BOTH_FORMS_OK`로 막는다.
2. `generate-one-page.ts` — 프롬프트를 다시 썼다(낱말은 한 낱말·같은 품사·진짜 반대말, 어법은 code·cue·wrongWhy를
   반드시 적게 한다). 코드 검사도 늘렸다: 밑줄이 근거까지 덮게 구간을 넓히고, 그 문장에 두 번 나오는 자리는 버리고,
   조동사 뒤 동사원형을 막고, 오답이 굴절·기능어 하나만 다른지 본다.
3. `one-page-verify.ts`(새로 만듦) — 만든 뒤 값싼 모델로 항목을 하나씩 되묻는 검수. 어법(둘 다 맞는가, 설명이 참인가,
   밑줄이 맞는가), 동의어·반의어(이 뜻·품사에 맞는가), 지칭어(정말 그것을 가리키는가), 해석(요약문·표현 뜻)을 본다.
   버리면 겹치지 않는 것으로 다시 뽑아 어법 4개 이상, 낱말 7개 이상을 채운다.
4. 지칭 정리 — 본문에는 작은 위첨자 번호(주황)와 점선 밑줄, 아래에는 "지칭 정리" 칸을 새로 넣었다.
5. `ONE_PAGE_CONTENT_VERSION`을 `op-4`로 올려 예전 자료는 열 때 한 번 새로 만든다.

## 값과 시간

지문당 gpt-5-mini로 입력 약 15,000·출력 약 12,000토큰, 100~220초.
그중 검수는 네 번 호출에 입력 3,246·출력 2,994토큰(실측 평균) = 지문당 약 9.5원이다.
전체는 지문당 약 33원으로 예전(약 8원)보다 늘었지만 차감(80크레딧)의 절반 아래다.
검수를 gpt-4o-mini로 내리면 약 3원이지만, 두 형태가 다 맞는지 가리는 판단이 약해 쓰지 않았다.

## 되짚어 볼 것

- 편지글처럼 문장이 짧고 쉬운 지문은 낼 만한 어법 자리가 적어 4개를 겨우 채운다.
- 어법 이름표(포인트 이름)가 실제로 묻는 원리와 다른 경우가 아직 남는다. 설명은 맞다.
- 지칭어는 지문에 따라 0~4개다(대명사가 적은 지문은 적게 나온다). 없는 것을 억지로 만들지 않는다.
- 검수가 "쉬운 낱말"이라며 많이 빼면 낱말이 너무 줄어, 7개 아래로는 빼지 않게 막아 두었다.
